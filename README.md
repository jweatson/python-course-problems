# Python Crash Course Problems

Programming problem sheets for Python programming crash course.

## How to use this

- Click the green button that says "code" above and then click "Download ZIP".
- Unzip the folder (Macs should do this automatically).
- In Google Colab, click "Upload Notebook", then drag the module's problem sheets in.
- Colab will then load.

## How to upload non-notebook files to Colab
- In the sidebar of Colab, click the button that looks like a folder ("files").
- Drag the file into the tab that appears, or click the upload button (shaped like an up arrow).
- If it fails to upload, press the refresh button next to the upload button, and try again.
